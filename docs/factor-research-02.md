# 因子研究 02:中小盘港股 —— 四个陷阱与一个否定结论

> 2026-07-23 · 数据源 富途 OpenD · 港股 · 2017-06 ~ 2026-07

## 结论先行

**没有找到可交易的 alpha。** 但这一轮的价值不在于"没找到",而在于:
研究装置里原本有两个 bug、两个方法论陷阱,它们联手能凭空造出
「净年化 78.7%、夏普 1.31」的假结果。全部修掉之后,这个结果归零。

**在修好度量工具之前,任何"发现"都不算数。**

---

## 实验设计

| 项 | 值 |
|---|---|
| 标的池 | 港股中小盘(市值 10~200 亿),按今日成交额取前 50 |
| 对照池 | 内置大盘池 43 只,**按行业代表性挑选** |
| 区间 | 2017-06-20 ~ 2026-07-23(交易日轴 2237 天) |
| 因子 | 11 个(反转/动量/低波/流动性/价值) |
| 前瞻期 | 5 日、20 日,**步长 = 前瞻期**(不重叠) |
| 成本 | 单边 20bp(佣金+印花税+滑点) |

标的池由 `scripts/build_universe.py` 构建。关键前提:
`get_stock_basicinfo` 与 `get_market_snapshot` **不消耗历史K线额度**,
所以能先免费筛完全市场 3781 只,再把稀缺额度(100只/30天)只花在入选者身上。

## 陷阱一:按数组下标做"截面"(bug,已修)

横截面研究的前提是**同一天比较**。但各标的上市时间不同、停牌天数不同,
bar 数量实测从 1483 到 2237,差了整整 3 年。

按数组下标 `close[t]` 对齐时,`index[250]` 落在 **18 个不同日期**上
(2018-06-25 到 2019-03-20+)—— 等于拿 A 股票 2018 年的因子值,
去配 B 股票 2019 年的收益。算出来的 IC 没有任何意义。

**修法**:`align_by_date()` —— 日期并集做统一交易日轴,上市前置 None,
生命周期内停牌前向填充,最后一根 bar 之后不填充(退市不能当作零涨跌)。

修复前后,反转_5日@5日 的 t 值从 2.85 变成 2.26,结论直接翻转。

## 陷阱二:前复权导致负价(bug,已修)

单期收益出现 **−613%**。收益率的数学下界是 −100%,
低于这个数就不是市场跌了,是数据错了。

根因:**前复权(QFQ)从历史价里逐次减去分红**,跨年累计分红一旦超过
当年股价,调整后价格变成负数。实测 8 年期 50 只港股中 5 只中招,
01114 有 1013 根 bar 价格为负,最低 **−7.26**。

**修法**:研究一律用**后复权(HFQ)** —— 锚定最早价格向后放大,永不为负。
另加 `sanitize()` 体检,发现非正价格整只剔除(剔掉 4 只)。

> 实时快照仍用 qfq 且**是刻意的**:只回看约一年不会出负价,
> 而它保持「最新价 = 真实市价」,下单价位判断才对得上。

## 陷阱三:IC 不等于盈亏

数据修干净后,低波_60日 拿到 IC **+0.0663**、t=2.72,看着像个好因子。
但分层回测里 Q5(最低波动,应该是多头)垫底,Q1 领先,多空组合 **−31%**。

逐期比对发现 IC 与分层价差其实高度相关(+0.726),矛盾出在**尾部**:
最差一期 Q5−Q1 = **−59.6%,而同期 IC 是 +0.28**。

即:大多数股票确实按预测排序(秩相关为正),但最高波动那一档
在反弹期集体暴涨。**秩相关看不见涨幅大小,钱却在尾部。**

**教训**:IC 只是入场券,分层单调性 + 扣费后多空收益才是判决。
`factor_backtest.py` 因此用**中位数**判单调性(抗离群),并强制打印
|r|>50% 的极端收益,防止均值被离群值绑架后当成"经济现象"。

## 陷阱四:选池的前视偏差(致命)

修完前三个之后,**低成交额**是唯一全项通过的因子:

- IC 0.0723,t=3.00,是唯一挨到 Bonferroni 门槛(22 次检验 → |t|>3.06)的
- 单调 3/4,换手仅 19.4%/期,**盈亏平衡成本 1232bp**
- 净年化 **78.70%**,夏普 **1.31**,t=3.74

看起来非常像真东西。但分段检验暴露了问题:

| 时段 | 净年化 |
|---|---|
| 2018-06 ~ 2021-01 | **−1.91%** |
| 2021-02 ~ 2023-10 | +101.97% |
| 2023-11 ~ 2026-06 | +181.54% |

**逐段递增、最早一段为零** —— 这是前视偏差的指纹。

机制:标的池按**今天**的成交额挑,因子买的是**当年**成交额最低的股票。
一只沉寂多年后暴涨的股票,会同时满足三件事——今天活跃所以入选、
沉寂期因子排名靠前、随后收益爆表。越接近选池日,这个偏差越强。

**决定性验证**(零额度成本):把同一因子跑在**按行业代表性挑选**的大盘池上。

| | 大盘池(无流动性选池偏差) | 中小盘池(按今日成交额挑) |
|---|---|---|
| 净年化 | **1.17%** | 78.70% |
| 夏普 | 0.06 | 1.31 |
| t 值 | 0.26 | 3.74 |
| 单调性 | ✗ 1/4 | ✓ 3/4 |
| 分段 | −19.96 / +26.22 / +2.08 | −1.91 / +101.97 / +181.54 |

同一因子、同一区间、同一份代码,**只换选池方式,77 个百分点的"alpha"就消失了**。

## 修正后的全因子结果(中小盘池,46 只)

多重检验修正:22 次检验,Bonferroni 门槛 **|t| > 3.06**。

| 因子 | 前瞻 | IC | ICIR | t | 判定 |
|---|---|---|---|---|---|
| 低波_60日 | 5日 | 0.0425 | 0.169 | **3.36** | 过门槛,但分层反向 → 不可交易 |
| 低成交额 | 5日 | 0.0391 | 0.160 | **3.18** | 过门槛,但选池偏差 → 归零 |
| 低成交额 | 20日 | 0.0723 | 0.301 | 3.00 | 同上 |
| 低波_20日 | 5日 | 0.0377 | 0.150 | 2.98 | 未过 |
| 反转_5日 | 5日 | 0.0313 | 0.149 | 2.97 | 未过 |
| 其余 17 个 | — | — | — | <2.8 | 未过 |

**没有一个因子同时满足:过多重检验 + 分层单调 + 扣费为正 + 分段稳定。**

## 下一步

按"最可能推翻结论"排序:

1. **做真正的时点标的池** —— 每个调仓日只用当时可得的信息选池。
   这是唯一能根除陷阱四的办法。受额度限制(见下),需下个窗口做。
2. **扩大截面** —— 46 只分 5 档,每档仅 9 只,分档收益噪声很大。
   截面因子研究通常需要 200+ 标的。
3. **换因子族** —— 价量因子在港股中小盘上已基本证否。
   要找 alpha 得转向非价量数据(财报、公告、资金流)。

## 补课:工厂缺的那一层(2026-07-23 已补)

四个错误里没有一个能被原八层架构拦住 —— 数据层不校验、评估层只质疑
策略逻辑、回测层没有横截面能力。这是**架构缺陷**,不是脚本笔误。已补三处:

### ① 数据层:体检门禁 `src/qsf/data/quality.py`

原先 `normalize_prices` 会**静默剔除**非法 bar —— 01114 在前复权下
1728 根只剩 715 根,序列残缺却毫无提示。静默降级比直接报错危险得多。

新门禁**先测量、再报告、超阈值阻断**:

| 检查 | 阈值 | 致命 |
|---|---|---|
| 非正价格 | >2% 的 bar | 是 |
| 最高价 < 最低价 | 任意 | 是 |
| 单日收益 ≤ −100% | 任意(数学不可能) | 是 |
| 零成交比例 | >10% | 否 |
| bar 数量比值 | >1.2 → 禁用下标对齐 | 否,但必须可见 |

已接入 `OpenDDataProvider`,报告挂在 `provider.quality` 上供评估层审问。

### ② 回测层:横截面能力 `src/qsf/backtest/cross_section.py`

`Panel` 按日期对齐(上市前置空、生命周期内前向填充、退市后不填充),
`run_factor()` 产出 `FactorEvidence` 并强制走**四道关**:

```
① 多重检验  |t| > Šidák 门槛(22 个假设时 3.04,不是 1.96)
② 分层单调  Q1→Q5 逐级递增 ≥ 75%
③ 扣费为正  net_annual > 0
④ 分段稳定  三段全为正 ← 前视偏差探针
```

因子研究不再游离于 `scripts/` 之外,受 schema 契约约束。

### ③ 评估层:质疑者先审证据

原质疑者只盯过拟合与参数,火力对着错误的靶子。现在**顺序颠倒**:
先审数据可信度 → 再审证据链 → 最后才审策略逻辑。
数据致命问题**一票否决**(REJECT 而非 REVISE)——
在错的数据上调参只会得到更精致的错误。

### 验收:用真实数据重跑当初那个假因子

```
因子证据 · 低成交额 · 46只 × 99期 (2018-06-25~2026-06-15)
  IC +0.0723  ICIR 0.301  t=3.74 (门槛 3.04)
  单调 75%  换手 19.4%/期
  毛年化 80.38% → 净年化 78.70%  夏普 1.31
  分段 -1.9% / +102.0% / +181.5%

四道关: ✓多重检验  ✓分层单调  ✓扣费为正  ✗分段稳定  → 不通过

质疑者判决: REJECT (置信 0.9)
  ✗ 各标的 bar 数量 1483~2237,若按数组下标做横截面,比较的根本不是同一天
  ✗ 收益逐段递增且最早一段为负,这是**前视偏差**的典型指纹
  → 标的池选法「按今日成交额取前50」需改为时点重建,并在无偏池上交叉验证
```

**工厂现在能拦住它自己当初放行的东西。** 这是这轮补课唯一有意义的验收标准。

## 实跑一轮工厂(2026-07-23)

配置 `configs/opend-hk.yaml` —— 富途 OpenD 真实数据、港股大盘池 43 只、
309 根日K(约 1.2 年)。数据体检:0 剔除、0 致命、bar 数量整齐。

### 结果:55 个提案,0 个通过

补完基准与样本外两道关之后,没有一个策略活下来。淘汰漏斗:

| 淘汰原因 | 命中 |
|---|---|
| 跑输买入持有 | 32 |
| 样本外跑输基准 | 24 |
| 交易样本 <10 笔 | 34 |
| 超额为正但风险调整后更差 | 2 |

### 过程中发现的两个评估层漏洞

**漏洞一:没有基准比较 → 分不清 alpha 和 beta**

首轮有 2 个策略通过,其中 **09999 网易**:

| | 策略 | 买入持有 |
|---|---|---|
| 收益 | +21.7% | **+25.6%** |
| 夏普 | 0.67 | **0.70** |

跑输"什么都不做",收益和夏普双双落后,却拿到评分 1.0、三角色全票通过。
全局看更明显:每只取最优策略,只有 **14/43(33%)** 跑赢买入持有,
而同期 43 只中位涨幅 **+26.6%** —— 这轮港股大涨,多数漂亮夏普只是 beta。

**漏洞二:没有样本外分割 → 分不清边缘和拟合**

补上基准后只剩 **09618 京东**(超额 +49.0%,夏普 1.19 vs -0.02),看着很强。
拆开样本内外:

| 时段 | 策略 | 基准 | 超额 |
|---|---|---|---|
| 训练段(前 216 根) | +44.4%(夏普 1.93) | −26.4% | **+70.8%** |
| 检验段(后 93 根) | **−0.6%**(夏普 0.09) | **+28.5%**(夏普 1.94) | **−29.2%** |

全部超额都在样本内。样本外一分没赚,而躺着不动赚 28.5%。
机制清楚:均值回归在震荡下跌段有效,转成单边上涨就被反复打脸
(它当时仍持空头 -1)。成本能扛到单边 35bp,但边缘根本不存在。

它还是**从 55 个候选里挑的第一名**(超额中位数 −14.0%)—— 挑最大值。

### 已补的三道关

| 关口 | 实现 | 阻断 |
|---|---|---|
| 跑赢买入持有 | `BacktestMetrics.benchmark_return` / `excess_return` | 是 |
| 样本外仍跑赢 | `oos_return` / `oos_excess`(后 30%) | 是 |
| 多重检验 | `n_candidates` → 压低信心 + 复现建议 | 否 |

第三条**刻意不阻断**:它对每个候选都成立,一旦计入 concerns,
只要提案数 ≥10 就永远不会有策略通过 —— 那是把关口焊死,不是提高门槛。

### 两点已知局限

1. **不可复现**:同一配置相隔几分钟两次运行给出 55 vs 47 个提案。
   实时数据在盘中变动 → 特征变 → 洞察变 → 提案数变。研究用途需固定
   `end_date` 快照,否则结论无法比对。
2. **成本模型偏乐观**:回测用 7bp/单边,港股实际含印花税约 15~25bp。
   09618 的敏感性测试显示能扛到 35bp,但换手高的策略要留意。

## 状态条件化检验(2026-07-23):条件化救不回价量信号

09618 的失败看起来像「策略有隐含前提而没写下来」——均值回归在震荡段有效、
转单边即失效。若真如此,出路就是把适用条件显式化。**这个假设可以直接测。**

单标的样本太小,所以把 43 只港股大盘池化(8 年、8.9 万个观测),
按状态分桶,每桶仍有上万观测。对照组是同桶的买入持有。

### 结果:两个信号在所有状态下都跑输

| 信号 | 最好的桶 | 最差的桶 | 显著为正的桶 |
|---|---|---|---|
| 均值回归 | Q2 趋势强度 **−12.42%** | Q5 **−17.84%** | **0 个** |
| 趋势跟随 | Q3 趋势强度 −0.93%(t=−0.18) | Q5 **−23.56%** | **0 个** |

均值回归 5 个趋势桶**全部显著为负**(|t| 3.28~4.19,修正门槛 3.11);
连最该有效的"最震荡"桶(趋势强度 0.000~0.044)都跑输 14.91%。
按波动率分桶结论相同。

而且均值回归的策略日均本身就是负的(−0.033%/日 ≈ 年化 −8.3%)——
不是"跑输大盘",是自己就亏钱。

**假设被证伪:这两个信号不是状态依赖,是根本没有边缘。**

### 一个结构性发现:做空放弃了正漂移

所有桶的基准日均都是正的(+0.011% ~ +0.082%)。多空择时有一半时间
在做空或空仓,等于主动放弃标的的正漂移。把仓位从 {−1,0,+1} 改成 {0,+1}
(默认持有,只在看空时离场):

| 信号 | 多空(趋势强度 Q1~Q5) | 只多 |
|---|---|---|
| 均值回归 | −14.9 / −12.4 / −14.1 / −17.4 / −17.8 | −9.4 / −7.1 / −9.1 / −11.6 / −12.4 |
| 趋势跟随 | −8.2 / −1.8 / −0.9 / −12.7 / −23.6 | −4.2 / −0.9 / **−0.5** / −6.6 / −12.6 |

**去掉做空,缺口缩小约一半。** 最好的情形(趋势跟随只多、中等趋势强度)
基本追平买入持有(−0.47%,t=−0.18),但仍没有一个桶显著为正。

> 追平基准却只有部分时间在场,理论上意味着更低风险 ——
> 但本检验只测收益差,**没有测风险**,不能据此宣称风险调整后更优。

### 对"该如何做策略生产"的含义

择时(何时在场)这条路,在港股大盘股上用价量信号已被三次独立检验否定:
单标的样本外、全池分状态、多空与只多两种仓位。

未被干净否定的方向:
1. **选股而非择时**(横截面)—— 因子研究失败那次标的池有前视偏差,
   用时点池重做才算数。
2. **非价量信息** —— 新闻、财报、资金流。工厂的新闻层目前还是 mock。
3. **风险管理而非收益预测** —— 不预测方向,只控制回撤与仓位。

工具:`scripts/regime_conditional.py`(`--long-only` 切换仓位约束)。
